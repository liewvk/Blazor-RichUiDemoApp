# Blazor Rich UI Demo App

A comprehensive demonstration application showcasing advanced UI/UX patterns and rich component implementations in Blazor, based on **Mastering Blazor with Visual Studio 2026 Chapter 23**.

## Overview

This project exemplifies best practices for building sophisticated, responsive user interfaces with Blazor. It serves as both a learning resource and a practical reference for implementing complex UI components and interactive features in modern web applications.

## Features

- **Rich Component Library**: Advanced Blazor components for building professional UIs
- **Responsive Design**: Mobile-first approach with CSS Grid and Flexbox layouts
- **Interactive Demonstrations**: Real-world examples of common UI patterns
- **Best Practices**: Implementation following Blazor and web development standards

## Technology Stack

- **Blazor**: Microsoft's web framework for building interactive web applications with C#
- **HTML/CSS**: Semantic markup and modern styling techniques
- **C#**: Backend logic and component interactivity

## Project Structure

```
Blazor-RichUiDemoApp/

├── wwwroot/            # Static assets (CSS, JavaScript, images)

```

## Getting Started

### Prerequisites

- Visual Studio 2026 or later
- .NET 9.0 or higher
- Blazor WebAssembly or Server runtime

### Installation

1. Clone the repository:
```bash
git clone https://github.com/liewvk/Blazor-RichUiDemoApp.git
cd Blazor-RichUiDemoApp
```

2. Open the solution in Visual Studio 2026

3. Build and run the application:
```bash
dotnet run
```

4. Open your browser and navigate to `https://localhost:5001`
